# Plan the day with time blocks

Time blocks need access to your calendars and an iCloud calendar account on the Mac or iPad.

## Create a block

In the Calendar, drag down in empty space in a day's Calendar column. It can be any time, also in the future. Fill in the title and, if you like, the project, then save. On the iPad, long-press and drag, or draw with Apple Pencil.

## Change or delete a block

Drag a block to move it, also to another day, and drag its edges to resize it. Double-click it or press Return to open the editor, which has Delete. Delete or ⌫ removes selected blocks, and ⌘Z brings them back. A change to a recurring event applies to that occurrence only.

## Use another calendar

By default the app uses an iCloud calendar named "Time Blocks". To change that, open Settings, Calendar, Time blocks, and choose another writable iCloud calendar, or "New Calendar…". The choice applies on all your devices, and events already in the chosen calendar then count as time blocks.

## Show other calendars beside your plans

Under Settings, Calendar, check the calendars in "Calendars to show". Other devices that have the same calendars follow.

## Create blocks from a script

A time block is an ordinary calendar event, so any calendar tool can create one. To link it to a project, either set the event's URL to `timetracking://project/<uuid>`, or add a first notes line `Project: <name>` that names exactly one active project. A URL wins, because it survives renames. If neither applies, the block is unlinked, and its tooltip says why.

## Turn a block into an entry

Hover over the block and click "+", or drag it into the Tracked column. The popover shows the block's title as the task and its project. The block itself stays as it is. A block entirely in the future can't become an entry.
